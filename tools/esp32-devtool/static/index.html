🧪 Deep Hardware Pin Diagnostic

This engine performs physical electrical verification to detect if wires or components are truly connected:

1. Pull-Up / Pull-Down Resistance Probe: Measures whether a pin floats freely or is tied to VCC, GND, buttons, or resistors.
2. I2C Bus Active ACK Scan: Checks if peripherals (OLED display at 0x3C, Codec at 0x18, RTC) physically acknowledge.
3. Boot Telemetry Sniffer: Parses XiaoZhi kernel boot logs to verify camera, display, audio, buttons, and battery monitor.
